x402 – HTTP 402 Machine Payments

        

          
x402 lets AI agents, scripts, and CLIs call paid endpoints without a browser session.
          Instead of SIWE login, the caller sends an X-Payment header with a base64-encoded on-chain payment proof.

          
Paid endpoints on this agent:

          
    
            
  • POST /x402/llm – LLM chat (0.5 SPAT)
    • 
            
  • POST /x402/workflow – Workflow execution (3 SPAT)
    • 
          

          
Payment flow: approve SPAT → call charge() on the Usage contract → encode receipt as base64 JSON → add X-Payment header → call endpoint.

          
If payment header is missing or invalid, the endpoint returns HTTP 402 with a accepts[] array describing what's needed.

        

        

          
          

        

      

      

        
MCP Server (Model Context Protocol)

        

          
The MCP server runs on port 8788 and exposes SPAT Agent capabilities as tools for Claude, Cursor, and any MCP-compatible client.

          
Add to your Claude Desktop / Cursor config:

          
{
  "mcpServers": {
    "spat-agent": {
      "url": "http://localhost:8788"
    }
  }
}

          
Available MCP tools: spat_llm_chat, spat_build_app, spat_create_token, spat_social_growth, spat_agent_info, spat_a2a_call
