SPAT Agent

Wallet login + owner signature flow for SPAT-billed tasks.

1) User Login (wallet signature)

2) Create Task (SPAT billed)

Backend will return EIP-712 typed data that must be signed by owner EOA.

3) Owner Approves Spend Signature (Relayer Mode)

Relayer mode requires backend RELAYER_PK.

4) Direct Mode (owner submits tx in wallet)
